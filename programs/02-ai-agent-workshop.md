# AI Agent Workshop

**Format:** Half day, hands-on (laptops required)
**Best for:** teams, colleges, in-house marketers, association pre-cons
**Fee:** $5,000 U.S. / $7,500 international + travel

## Description

We do not lecture about AI. We put the room in the driver’s seat.

Attendees follow SOPs and deploy working agents on a real business — content, ads, or client work — while Dennis narrates. The session ends with something that runs: a published page, an audit, a follow-up agent, a map listing plan. Johns Hopkins ran this as a small-cohort practicum. Association rooms run it as a workshop the day before the keynote.

Young AI Builders (the same people Local Service Spotlight certifies) often co-present so the audience sees the model, not just the founder.

## Takeaways

- Build one working agent in the room
- Copy the SOP, don’t copy the vibe
- See how colleges and trade groups staff this with certified young adults
